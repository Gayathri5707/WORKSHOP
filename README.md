# RISC-V MYTH Workshop

Welcome to my RISC-V MYTH Workshop repository.

This repository contains my learning journey through the RISC-V MYTH Workshop, including the practical activities, observations, commands, and outputs completed during each session.

## About the Workshop

The workshop introduces the fundamentals of the RISC-V architecture and provides hands-on experience with processor design concepts, the RISC-V software toolchain, assembly programming, and hardware description using TL-Verilog.

## What I Learned

Throughout the workshop, I am building an understanding of:

* RISC-V instruction set architecture
* RISC-V registers and instructions
* Assembly-level programming
* Compilation and execution of RISC-V programs
* ABI and register conventions
* Basic processor organization
* TL-Verilog concepts
* Digital hardware design
* Simulation and verification
