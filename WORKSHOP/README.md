# RISC-V MYTH Workshop

## Microprocessor for You in Thirty Hours (MYTH)

This repository contains my work and learning progress from the **RISC-V MYTH Workshop**.

The workshop provides a hands-on introduction to RISC-V, beginning with the instruction set and software toolchain and progressing toward the design of a pipelined RISC-V processor.

---

## Workshop Progress

| Day       | Topic                    | Description                                                                                     |
| --------- | ------------------------ | ----------------------------------------------------------------------------------------------- |
| **Day 1** | RISC-V ISA               | Introduction to the RISC-V instruction set architecture and GNU compiler toolchain              |
| **Day 2** | RISC-V ABI               | Understanding the RISC-V Application Binary Interface, registers, memory and basic verification |
| **Day 3** | TL-Verilog & Makerchip   | Digital logic design using TL-Verilog and the Makerchip platform                                |
| **Day 4** | RISC-V Microarchitecture | Understanding and building the microarchitecture of a RISC-V processor                          |
| **Day 5** | Pipelined RISC-V CPU     | Pipelining, hazards, memory operations and completing the RISC-V CPU                            |
